01. what is tmxssh?

tmxssh is a free, open-source tool that starts an OpenSSH server on Termux (Android) in the background. In one step it turns your Android device into an SSH host, so laptops, other phones and tablets on the same network can SSH in and access your terminal.

No complex config. Just install and type tmxssh — it auto-installs openssh, guides you through setting a login password, and prints the exact command the other device needs to connect.

02. why use tmxssh?

  • One command install — lands straight into your system path.
  • Auto-starts sshd in the background, no config files to edit.
  • Auto-installs openssh when it's missing.
  • Guided password setup on first run — Termux ships with no login password.
  • Prints your connect info — IP, port and user, ready to copy.
  • Scannable QR code — point another phone at it to grab the ssh command.
  • Change port & reset password anytime with simple subcommands.
  • LAN only, no cloud — devices connect directly over your local network.

03. quick start

tmxssh

That's it. On other devices over the same network:

ssh -p 8022 user@192.168.1.x

04. commands

CommandWhat it does
tmxsshauto-start (if needed) + show connect info
tmxssh startstart sshd in the background
tmxssh stopstop sshd
tmxssh restartrestart sshd
tmxssh statusshow running state
tmxssh infoshow IP / port / user
tmxssh setpassset or change SSH login password
tmxssh port Nchange SSH port (default 8022)
tmxssh qrshow a scannable QR connect code
